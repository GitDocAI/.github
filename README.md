# .github

This repository hosts the **GitHub organization profile** for [@GitDocAI](https://github.com/GitDocAI).

The visible content lives in [`profile/README.md`](./profile/README.md) — GitHub renders it on the organization landing page at <https://github.com/GitDocAI>.

## Editing the org profile

1. Edit `profile/README.md`.
2. Commit and push to `main`.
3. GitHub updates the org page within a few minutes.

Keep the content aligned with the positioning in the main [GitDocAI](https://github.com/GitDocAI/GitDocAI) repo's `README.md` and `landing-features.md`.
